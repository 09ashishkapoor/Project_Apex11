Install

Two taps, then it is yours.

Android Chrome, Edge, Brave

  1. Open mantrini.jaikhyapaparampara.com
  2. Tap Install, or menu ⋮ then Add to Home screen
  3. It opens full screen, with the trikoṇa icon

iPhone & iPad Safari

  1. Open the same address in Safari
  2. Tap Share, then Add to Home Screen
  3. Open it from the Home Screen, not a bookmark

On iPhone, install rather than bookmark. Safari may clear a website's stored data after seven days unused; an app on the Home Screen is kept.
